# Equipamentos de Controle de Acesso

## Introdução

Os sistemas de controle de acesso são compostos por diversos equipamentos que trabalham em conjunto para identificar usuários, validar permissões e controlar a entrada e saída de pessoas em ambientes corporativos, industriais, comerciais e residenciais.

Cada dispositivo possui uma função específica dentro da arquitetura do sistema, sendo responsável pela coleta de informações, comunicação com controladoras e execução das ações de liberação ou bloqueio do acesso.

---

# Relógio de Ponto

## O que é?

O relógio de ponto é um equipamento utilizado para registrar a jornada de trabalho dos colaboradores, permitindo o controle de horários de entrada, saída, intervalos e horas extras.

Os registros podem ser realizados utilizando diferentes métodos de identificação, como:

- Biometria
- Cartão RFID
- Senha
- QR Code
- Reconhecimento Facial

### Principais aplicações

- Controle de jornada
- Gestão de frequência
- Controle de acesso (em alguns modelos)
- Integração com sistemas de RH

---

# Catracas

## O que são?

As catracas são dispositivos utilizados para controlar o fluxo de pessoas em locais onde é necessário restringir ou registrar acessos.

Seu funcionamento depende da validação realizada por um sistema de controle de acesso.

Após a autenticação do usuário, a catraca libera a passagem.

### Tipos

- Catraca pedestal
- Catraca balcão
- Catraca PNE
- Catraca de vidro

### Métodos de autenticação

- Biometria
- RFID
- QR Code
- Reconhecimento Facial

---

# Torniquetes

## O que são?

Os torniquetes são equipamentos utilizados em ambientes que exigem maior nível de segurança.

Ao contrário das catracas convencionais, eles impedem totalmente a passagem até que a autenticação seja validada.

São comuns em:

- Indústrias
- Data Centers
- Aeroportos
- Centros logísticos
- Áreas restritas

---

# Cancelas

## O que são?

As cancelas controlam o acesso de veículos em estacionamentos, condomínios e empresas.

Podem ser integradas a diversos sistemas de identificação.

### Métodos de acionamento

- Cartão RFID
- TAG veicular
- Reconhecimento de placas (LPR)
- Controle remoto
- Aplicativos
- Botão de liberação

---

# Leitores Biométricos

São dispositivos responsáveis pela identificação dos usuários através de características físicas.

As tecnologias mais comuns são:

- Impressão digital
- Reconhecimento facial
- Palma da mão
- Íris

A biometria oferece maior segurança por utilizar características únicas de cada indivíduo.

---

# Leitores RFID

Os leitores RFID realizam a identificação por radiofrequência.

Quando um cartão ou TAG é aproximado, o leitor transmite seu código para a controladora, que verifica se o usuário possui autorização para acessar o local.

É uma das tecnologias mais utilizadas em sistemas de controle de acesso.

---

# Fechaduras Eletromagnéticas

As fechaduras eletromagnéticas utilizam força magnética para manter portas travadas.

Quando recebem o comando da controladora, liberam temporariamente o acesso.

São amplamente utilizadas em:

- Escritórios
- Hospitais
- Escolas
- Condomínios

---

# Controladoras de Acesso

A controladora é considerada o cérebro do sistema.

Ela recebe as informações dos leitores, consulta as regras de acesso e decide se o usuário poderá entrar ou não.

Entre suas funções estão:

- Gerenciar permissões
- Registrar eventos
- Acionar fechaduras
- Comunicar-se com o software de gerenciamento

---

# Fontes de Alimentação

As fontes fornecem energia para todos os dispositivos do sistema.

Uma alimentação elétrica estável é fundamental para garantir o funcionamento contínuo dos equipamentos.

---

# Nobreaks

Os nobreaks mantêm o sistema em funcionamento durante quedas de energia.

Além de evitar interrupções, ajudam a proteger os equipamentos contra oscilações elétricas.

---

# Considerações Finais

Os sistemas de controle de acesso são compostos por diversos dispositivos que trabalham de forma integrada para garantir segurança, rastreabilidade e controle da circulação de pessoas e veículos.

Compreender a função de cada equipamento é essencial para realizar instalações, manutenções, diagnósticos e futuras integrações com tecnologias como Internet das Coisas (IoT), automação predial e sistemas embarcados.
