# Access Control Fundamentals

Este repositório documenta meus estudos sobre sistemas de controle de acesso, infraestrutura, protocolos de comunicação e tecnologias utilizadas em soluções de segurança eletrônica.

## Objetivos

- Estudar os fundamentos de controle de acesso
- Documentar conceitos importantes
- Compartilhar conhecimento
- Criar uma base para futuros projetos de IoT

## Conteúdo

- Arquitetura de sistemas
- Equipamentos
- Protocolos de comunicação
- Infraestrutura
- Redes
- Manutenção preventiva
- Manutenção corretiva
